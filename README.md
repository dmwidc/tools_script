# 工具脚本集合

> 一个用于存放常用工具脚本的 Git 仓库

## 📋 简介

本项目收集和整理日常开发中常用的工具脚本，方便快速查找和使用。

## ⚠️ 免责声明

**重要提示：** 本项目内的脚本主要用于内部运维，如果你不理解脚本用途，请勿轻易执行，避免破坏系统。

在使用任何脚本之前，请务必：
- 仔细阅读脚本内容，理解其功能和作用
- 在测试环境中先行验证
- 确保有系统备份或恢复方案
- 对脚本执行可能产生的后果负责

## 📁 项目结构

```
tools_script/
├── README.md          # 项目说明文档
└── [脚本分类目录]      # 按功能分类存放脚本
```

## 🚀 使用说明

### 方式一：克隆仓库到本地

1. 克隆仓库到本地：
   ```bash
   git clone <repository-url>
   ```

2. 根据脚本类型选择对应的脚本文件

3. 按照脚本内的注释说明使用

### 方式二：远程直接执行脚本

可以直接通过 curl 命令远程调用本仓库内的 `.sh` 脚本：

```bash
curl -fsSL <替换成脚本文件的RAW链接地址> | sudo bash
```

**示例：**
```bash
# 假设脚本文件路径为 scripts/install.sh
curl -fsSL https://raw.githubusercontent.com/username/tools_script/main/scripts/install.sh | sudo bash
```
